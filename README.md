# Product Preview Card Component

My solution to the [Product preview card component](https://www.frontendmentor.io/challenges/product-preview-card-component-GO7UmttRfa) challenge on Frontend Mentor. A product card for a perfume, with price, discount, and add-to-cart button.

![Product Preview Card Component on desktop](docs/screenshots/desktop.png)

<img src="docs/screenshots/mobile.png" alt="Product Preview Card Component on a phone-sized screen" width="260">

## Features

- Side-by-side image and details on desktop
- Image on top on mobile
- Original price shown struck through next to the sale price

## Built with

- Semantic HTML
- CSS with Flexbox and media queries

## Run locally

No build step or dependencies. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
